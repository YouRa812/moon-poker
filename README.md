# Moon Poker 🃏🔥

> **Техасский Холдем для смартфонов с локальным мультиплеером по Wi-Fi / коду комнаты и генератором отборных матерных реакций на любое игровое событие.**

Дизайн выполнен по мотивам футуристичного тёмного неоморфизма («Moon Poker») и адаптирован под игру одной рукой с мобильного телефона.

---

## ⚡ Особенности

- 📱 **Мобильная адаптация**: крупные тач-кнопки (Fold, Check/Call, Raise со слайдером), две карманные карты под углом внизу экрана, соперники дугой сверху, банк в центре.
- 🌐 **Локальный мультиплеер**: мгновенное подключение любого количества игроков в одной Wi-Fi сети по короткому 4-значному коду или QR-коду с экрана хоста.
- ⚙️ **Гибкие настройки стола**: хост может настроить стартовый стек, размеры блайндов (SB/BB) и таймер на ход (15, 30, 45, 60 сек).
- 🤬 **«Ультра-мат движок» (Reaction Engine)**:
  - Автоматические комикс-баблы с анимацией тряски над аватарами игроков при раздаче (мусор 7-2, карманные тузы), выходе флопа/терна/ривера (переезды, доезды), ставках, затяжке времени, олл-инах и шоудауне (победа, проигрыш, сплит, вылет).
  - Кнопка «МАТ» для быстрого вброса отборных матерных реплик в чат.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
cd client && npm install && npm run build && cd ..
```

### 2. Запуск сервера
```bash
npm start
```

После старта в консоли появится ваш локальный IP (например, `http://192.168.0.108:3000`).
Откройте эту ссылку на телефоне или отсканируйте QR-код в лобби игры.
